# Diah Platform

Luxury fashion rental marketplace for Algeria.

## Monorepo

```
diah/
  apps/
    mobile/      # Flutter customer / owner / store app
    admin-web/   # Next.js admin dashboard (prototype)
```

### Mobile (Flutter)

```bash
cd apps/mobile
flutter pub get
flutter run
```

### Admin Web (Next.js)

```bash
cd apps/admin-web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

**Demo admin login:** `admin@diah.dz` / `admin123`
